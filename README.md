# 短视频生成器 · 使用教程

> 一款基于 AI 的短视频自动生成工具。只需输入一个视频主题，即可自动完成「脚本撰写 → 素材匹配 → 配音 → 字幕合成」全流程，快速产出一条完整短视频。

## 一、简介

本系统是 MoneyPrinterTurbo 的多用户 Web 版本，支持账号注册登录、多租户隔离与任务管理。

**核心能力**

- AI 脚本生成：支持自定义文案要求与知识库检索
- 多素材来源：Pexels / Pixabay / Coverr / 本地素材 / 知识库 / 即梦 AI
- 多 AI 配音：Azure、SiliconFlow、Gemini、ElevenLabs、小米 MiMo、Chatterbox 等
- 字幕样式自定义：字体、字号、颜色、描边、位置、背景
- 任务管理：实时进度、暂停/恢复、重试、播放、下载

## 二、快速开始

1. **注册 / 登录**：首次使用请先点击「立即注册」创建账号，再用账号密码登录。
2. **填写主题**：进入工作台，在左侧「脚本」面板输入视频主题（必填），例如「春天的花海，一场说走就走的旅行」。
3. **生成脚本**：点击「生成脚本」，AI 自动撰写视频文案。
4. **生成关键词**：点击「生成关键词」，AI 从脚本中提取用于搜索素材的关键词。
5. **开始生成**：按需设置画面、配音、字幕后，点击底部「开始生成视频」。
6. **查看结果**：在「任务管理」中查看进度，完成后可「播放」预览或「下载」成片。

## 三、脚本面板

| 配置项 | 说明 |
| --- | --- |
| 视频主题 | 视频核心内容，**必填** |
| 视频语言 | 脚本语言，支持简/繁中文、英、德、西、法、俄、越、泰、土耳其语等 |
| 脚本时长（秒） | `0` 表示不限；非 0 时按约 4.2 字/秒换算目标字数 |
| 自定义文案要求 | 对脚本风格、结构、口吻的额外要求 |
| 自定义 System Prompt | 高级选项，留空使用系统默认 |
| 使用知识库 | 开启后可从知识库文档检索相关内容辅助生成脚本 |
| 视频脚本 | 可直接粘贴自写脚本，或点「生成脚本」由 AI 生成 |
| 视频关键词 | 用于搜索素材的关键词，逗号分隔，可点「生成关键词」自动提取 |

## 四、视频画面面板

| 配置项 | 说明 |
| --- | --- |
| 视频比例 | 横屏 16:9 / 竖屏 9:16 / 方形 1:1 |
| 拼接模式 | 随机（素材随机拼接）/ 顺序（按序拼接） |
| 素材来源 | Pexels / Pixabay / Coverr（在线素材库，需配置 API Key）、本地素材（上传自备视频/图片）、知识库（取用知识库素材）、即梦 AI（AI 生成图片） |
| 知识库层级 | 选择「知识库」或「即梦 AI」时，可指定分类层级（可选中中间层级聚合） |
| 本地素材 | 选择「本地素材」时，上传视频或图片文件 |
| 每片段时长 | 每个镜头时长，1–60 秒 |
| 剪辑速度 | 素材播放速度，0.1–3 倍 |
| 素材匹配脚本 | 开启后尝试让素材内容与脚本语义匹配 |

## 五、配音面板

| 配置项 | 说明 |
| --- | --- |
| 配音模式 | AI 配音（文字转语音）/ 上传配音（自备音频）/ 无配音 |
| TTS 服务器 | Azure TTS V1/V2、SiliconFlow、Google Gemini、小米 MiMo、ElevenLabs、Chatterbox |
| 音色 | 选择具体配音音色（男声/女声等） |
| 音量 / 语速 | 调节配音音量与播放速度 |
| 背景音乐 | 随机（内置曲库随机）/ 无 / 自定义（上传音乐），可调音量 |

## 六、字幕面板

| 配置项 | 说明 |
| --- | --- |
| 字幕开关 | 控制是否显示字幕 |
| 字体 / 字号 | 字幕字体与大小 |
| 文字颜色 / 描边颜色 / 描边宽度 | 字幕外观 |
| 字幕位置 | 顶部 / 居中 / 底部 / 自定义 |

## 七、任务管理

- **状态**：处理中、已完成、失败、已暂停、历史等。
- **进度**：处理中的任务实时显示进度条。
- **操作**：
  - 暂停 / 恢复：控制任务执行
  - 重试：失败任务重新提交
  - 播放：在线预览成片
  - 下载：下载视频文件
  - 删除：删除任务及其生成文件
- 列表每 2 秒自动刷新，也可点击表头右上角刷新按钮手动刷新。

## 八、设置

点击右上角「设置」按钮打开设置对话框：

- **界面**：默认字体、字号、字幕位置、文字颜色、默认语言、配音模式、TTS 服务器等默认值。
- **缓存**：查看缓存文件数与占用大小，可一键清理。
- **LLM**：配置 LLM 提供商、API Key、模型名、Base URL。
- **素材 API**：配置 Pexels、Pixabay、Coverr 的 API Key（使用在线素材库需要）。

> 部分设置（LLM、素材 API 等）需要管理员权限才能保存。

## 九、常见问题（FAQ）

1. **无法生成视频？** 确认已填写「视频主题」，且所选素材来源对应的 API Key 已配置。
2. **任务一直处理中？** 观察进度条；若长时间卡住，可尝试「暂停→恢复」，或删除后重试。
3. **视频没有声音？** 检查配音面板是否误设为「无配音」，或音量是否调为 0。
4. **字幕不显示？** 确认字幕开关已打开，字号与位置设置合理。
5. **在线素材搜不到？** 请确认已在「设置 → 素材 API」中配置对应平台的 API Key。
